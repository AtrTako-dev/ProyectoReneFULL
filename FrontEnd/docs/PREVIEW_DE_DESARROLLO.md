# Vista previa de desarrollo

La compilación Debug ofrece una ruta separada desde el acceso para recorrer las pantallas de cliente y administrador. Esta ruta solo modifica la navegación local: no inicia sesión, no contacta a la API, no carga datos y no cambia roles.

Las funciones con datos reales requieren una cuenta válida y una API accesible. El formulario de venta permanece deshabilitado en la vista previa para evitar envíos sin sesión. La compilación Release no incluye la ruta de exploración.
